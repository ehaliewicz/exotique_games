---- Description ----

Basic riichi mahjong.  Currently doesn't detect win conditions.
Has basic AI, but still under development.

Note: this is software rendered so should run fine without a discrete gpu, 
although it might have higher CPU usage than you expect.

---- Controls ----
Left/Right - select tile
A - draw
B - discard
X - call (PON a discarded tile/CHII a tile discarded by the last player)  (KAN not yet supported)
Y - riichi (discard and put yourself in riichi, currently just discards the first valid tile for riichi, sorry)
